Arabidopsis Thaliana Flowering Stage Classification using DINOv3
Overview

This repository contains the code, models, and analysis used to classify flowering stages of Arabidopsis thaliana from field images using self-supervised visual representations derived from Facebook AI Research’s DINOv3 model. The project focuses on distinguishing flowering and non-flowering states, including the presence of siliques, to support phenological analysis and downstream biological research.

The work emphasizes robust feature extraction from limited labeled data and evaluates the effectiveness of modern self-supervised vision transformers for fine-grained plant phenology classification.

Research Motivation

Accurate identification of flowering stages in Arabidopsis thaliana is critical for phenological studies, climate response analysis, and automated plant monitoring. Manual annotation of flowering stages is time-consuming and does not scale well to large image collections.

This project explores whether embeddings generated by large self-supervised vision models can capture biologically meaningful visual cues—such as petals and siliques—using a relatively small, carefully curated training set.

Methodology
Model

Backbone: facebook/dinov3-vitl16-pretrain-lvd1689m

Pretraining: Self-supervised learning on large-scale natural image datasets

Embedding Strategy:

Global pooled representation from the final hidden state

No fine-tuning of the backbone during training

Classification Pipeline

Image preprocessing using the DINOv3 image processor

Feature extraction via frozen DINOv3 backbone

Lightweight classifier trained on top of embeddings

Threshold tuning and evaluation on a held-out test set
